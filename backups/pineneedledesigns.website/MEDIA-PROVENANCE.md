# Current media classification — two A–Z lists

Updated November 7, 2026, using the owner’s latest labeling instruction. These two lists replace the earlier classification that called owner-supplied replacements or all existing media Confirmed. The first list contains original media labeled **Never lost** and Etsy-sourced recovery/import media labeled **Confirmed** (including renamed or losslessly cropped derivatives). The second list contains only **Unconfirmed** media: every other recovery, replacement, copy, extracted frame, or custom placeholder. Owner-supplied replacement media is now Unconfirmed under this rule.

Both lists are independently alphabetized by the full item name, then media type and slot. Collection covers are identified as collections. Classification is per file: a product with original or Etsy files and non-Etsy replacements can appear in both lists. This avoids assigning one misleading label to a mixed gallery.
