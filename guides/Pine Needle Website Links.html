Pine Needle website links and monitoring guide

Prepared for Chris Muha on October 21 2026

Use these links to manage Pine Needle Designs, review alerts, and locate saved recovery files.

Current setup

GitHub runs the uptime monitor and the catalog and file monitor every six hours. Both email muhachris297@gmail.com and work while both Macs are offline. Emails use notifications@notifications.pineneedledesigns.store.

The local scheduled job has been removed. Existing backup files remain saved. The GitHub monitors send alerts. A separate Daily Catalog and Media Backup workflow saves catalog records and uploaded media to this repository every 24 hours at 07:43 UTC. It does not automatically restore files. Checks can miss changes or brief outages between runs.

Costs and scheduling

GitHub Actions billing

Standard GitHub-hosted runner compute is free for public repositories. This repository is public; these checks do not use the included private-repository Actions minutes.

https://docs.github.com/en/billing/concepts/product-billing/github-actions

GitHub scheduling rules

Scheduled checks can be delayed or dropped. Public-repository schedules may be disabled after 60 days without repository activity.

https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule
